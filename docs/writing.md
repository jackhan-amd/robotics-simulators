# Writing guidelines

Write installation and execution instructions as complete, runnable steps. State required inputs, versions, configuration and expected checks. Keep claims tied to the evidence available for the named version, backend and scene.

Preserve commands, configuration values, numbers, citations, paths and source pins when editing prose. Distinguish previous validation from new execution, and report blockers with their cause and evidence.

Keep verbatim license notices unchanged. Review code, model and dataset permissions separately.
